# CRN Artifacts gallery photos

Place the workshop or finished-piece photos you want to use on the website in this folder. JPG, PNG, and WebP are all fine. Simple names such as `sign-1.jpg` or `panel-1.webp` are easiest to work with.

The current “What we make” cards are illustrative concepts, so files placed here will not appear on the page automatically. Once the photos are here, connect them to the gallery cards in `index.html`.
