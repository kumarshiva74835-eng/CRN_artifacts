# Maker profile photo

Place the maker's portrait photo in this folder and name it `owner.jpg`.
The landing page will show it beside the maker introduction in the hero section.

To change the short introduction, edit the `makerBioPlaceholder` text in
`script.js` in both the English (`en`) and Kannada (`kn`) translations.

The photo slot stays in place if `owner.jpg` has not been added yet.
